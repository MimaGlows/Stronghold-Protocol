## 定制功能

伪账号及头像、账号配置和隐私同步、接管审批、服务器统计及对局详情、匿名回放分享、中日配音、好友、标点、无线电、首页与选择页署名；另保留回放分块加载、图形回退、休整快照和邀请处理修复。具体约定见 [Windows 升级说明](WINDOWS-UPGRADE-024.md)、[回放](REPLAYS.md)、[好友](SOCIAL.md) 和 [通讯](COMMUNICATIONS.md)。

此源码对应正式运行版，不包含隔离匹配实验模式。正式实例的 737 个可提交文件在导入时逐项比对 SHA-256，全部一致；测试及开发配置取自该正式版升级时使用的源码目录。

## 在 Windows 上运行

安装 Node.js 22 或更高版本（原实例使用 24.19.0），双击根目录 `start-custom-windows.cmd`。该入口沿用原项目安装及资源准备流程，使用 `127.0.0.1:3000`、`SP_COMBAT=client`、`SP_VERIFY=off`、`TRUST_PROXY=auto`。可选的 `.runtime/node.exe` 优先使用；否则使用系统 Node.js。窗口按 Ctrl+C 正常停服。

远程访问按需另行配置，详见 [部署说明](DEPLOY.md)。玩家账号、头像、统计及回放保存在本地 `logs/`，新克隆不会携带现有实例的玩家数据。

游戏素材、字体、下载缓存、第三方构建、Node.js 可执行文件、依赖目录、玩家数据、密钥和本机环境配置不提交。按原项目安装流程获取依赖与素材；不要将 `public/assets/` 或 `logs/` 强制加入 Git。
