# Windows 定制 v0.2.4 合并（2026-10-11）

以官方 v0.2.3 为共同基线进行三方合并，将官方 v0.2.4 游戏规则、数据、渲染和布局更新合入现有定制实例。来源为 v0.2.4 标签源码及 SHA-256 已验证的官方更新包；不导入其他测试环境的账号或对局。官方规则与 Golden 变动依据见 [0.2.4 设计记录](history/0.2.4.md)。

虚拟账号、头像、配置、接管、好友、服务器统计、历史结算、匿名分享、中日配音和官方干员调配语音保持现有机制。统计仍由服务器保存，界面不提供导出、导入、清空或独立游玩记录入口。首页和模拟选择页保留组件拥有的两行署名；房间无署名。恢复入口仍为自制“继续当前对局”，候选取当前虚拟账号的实际活动对局，不恢复官方的本地恢复入口。

官方模拟规则改变后，待生成轨道必须匹配模拟引擎签名。旧 v0.2.3 内容指纹只在其已验证的旧引擎签名下允许重生成，不能在 v0.2.4 引擎上冒充兼容。已有完整帧仍按存档、快照、事件与资源结构验证，不按界面构建指纹失效。最近 30 条资格、退出不生成回放、跨账号共享保留规则不变；不恢复 72 小时清理，不重写旧存档。

渲染恢复合并官方的网络资源重试、限定次数的引擎重新挂载和同一对局数据重提交；模拟对象、时钟和当前战斗不重启。GPU 上下文实际丢失后使用现有简化视图，该挂载期间不再自动重建 GPU 上下文。回放仍按需分块、10 秒/块、8 MiB 解码上限、32 MiB LRU，跳转及关闭取消过时请求。首次切场的目标和请求序号校验、单位静态快照及场景清理保留。

官方共享装备库存耗尽时，候选意向标点与购买都不可用；普通未领取候选即使尚未轮到本人，也可按 Z 点击表达意向而不触发选择。服务器重新核对实际库存，避免过时视图发送售罄候选。标点 125 ms/10 秒 40 次、无线电独立限额不变。

Windows 浏览器验收使用本机 Chrome。官方渲染测试适配 Windows 的 ANGLE 后端和 fileURLToPath 截图路径；回放测试复制 QA 数据时解引用隔离目录的 Junction，不将生产数据链接到临时测试目录。

验收日志、截图、兼容性清单、发布校验、完整备份和回滚说明由本机交付报告记录。公网 HTTPS 的证书、Safari、另一台 Windows 11 设备的系统/GPU 崩溃原因与真实通知中心仍需对应环境验证。
