# Windows v0.2.3 定制合并

官方 v0.2.3 更新基于发布标签 1db8e51 合并，保留伪账号、头像、配置、服务器统计、30 条回放资格、分享、中日配音、Mac 好友通讯及两行署名。

干员调配与自选编队沿用官方 OperatorVoice 下拉选项（跟随全局／中文／日本語），替代旧设置中的独立干员语音列表。选项仍写入既有 voiceLanguage／voiceOverrides 账号配置，原偏好保留并由服务器同步，缺失台词沿用现有回退机制。

恢复本机对局只沿用官方按钮和弹窗。候选是当前完整伪账号，点击时由现有 identity.init、账号登录、会话重连及接管审批处理；不引入官方 sp.matches、本机多座位清单、noReplace 或 claimAt 协议。客户端 public/js/net.js 和服务端 server/net.js 沿用切换前实现。服务器重启或对局结束后无法恢复；已退出对局不会恢复，历史记录和回放不会变成可继续对局。

官方规则、模拟修复、开局全票重刷、文字大小、PWA 入口及新干员／模组随此次合并。生成数据直接来自官方发布包并合并已有非冲突素材索引；没有手改数值或恢复旧回放帧。官方恢复功能相关文档描述的是上游实现，本机差异以本文件为准。

测试源码保留伪账号身份测试；上游仅测试被排除恢复协议的 client-identity-handshake 用本机 resume-profile 与既有账号接管／重连测试替代。Mac 开发测试控制器改名为 mac-server.mjs，正式启动仍使用已有 Windows 入口。
