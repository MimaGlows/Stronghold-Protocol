# Mac 好友通讯重新合并到 Windows v0.2.2

2026-10-10，以已校验的 `Stronghold-Protocol-Windows-Social-Communications-20261009.zip` 为社交和通讯实现依据，保留 Windows v0.2.2 游戏规则、虚拟账号统计及最近 30 条记录的回放资格。没有导入 Mac 或验收账号数据。

## 操作与协议

- 好友抽屉、搜索、邀请、隐私和转盘使用 Mac 版本交互。头像／代号进入官方统计的对局记录；近期玩家读取服务器统计和 `socialRecentMatches`，保留最近五场完整参与者身份。
- 按住 Z 点击目标，短按松开立即发送；长按 300ms 打开转盘。触摸入口复用同一逻辑。标点独立限额为最短 125ms、滚动十秒最多 40 次；无线电保持最短一秒、十秒最多五次。只有校验成功的发送计数。断线不排队补发。
- 公共／个人悬赏卡片支持意向标点，未轮到本人也可标记当前可见、未领取的公共卡片。请求仅包含卡片索引及个人 `choiceId`；服务器生成名称，不执行选择操作。普通点击仍采用原有两步确认。
- 查看队友合法阵地可标点，战场切换只在服务器应答成功后改变观察目标，并隔离过时请求。BOSS 根据实际场地成员与镜像部署映射确定两半归属；降级视图显示完整双半场。战斗中仅允许空的合法部署地块。观战者只接收。
- 通讯沿用独立回放轨道，摘要不暴露该轨道，过期时一同清理；暂停及跳转不重复播放音效。没有恢复 72 小时清理。
