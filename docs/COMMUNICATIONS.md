# 游戏标点与无线电开发说明

以下保留 Mac 实现及历史验收记录。Windows v0.2.2 的当前协议、限流和实际检查以 [Windows 重新合并记录](MAC-SOCIAL-WINDOWS-20261010.md) 为准。

## 操作

- 按住 Z：左键短按标记游戏目标；在可部署地块上按住左键 300 ms 呼出转盘，拖动后松开。
- 转盘上方警告、右方敌人不见踪影、左方点赞；下方和中心取消。释放 Z、Esc、窗口失焦、指针取消均取消发送。
- X 开关无线电菜单，点击发送五句固定文字之一。与交流菜单互斥；接收无线电复用 `yourTurn` 音效，不播放人声。
- 出售默认改为 C。设置 → 快捷键可以修改全部动作，冲突通过交换解决。
- 触屏使用左下角“标点”和“无线电”按钮；标点按钮开关模式，地块长按拖动与鼠标一致。触摸按钮至少 44 px。
- 左下角最多五条消息，8 秒后消失；地块、已部署干员的临时标识显示 4 秒。查看其他战场时仅显示文字，镜头不会自动跳转。

标点模式捕获输入，不触发购买、部署、出售或详情。正在拖动、选择部署朝向、输入文字，以及设置、说明、历史回放等阻塞界面打开时禁用。最终结算、本局信息确认、策略选择阶段不提供发送入口。观战者仅接收；已淘汰的参赛玩家可以继续通讯。

## 数据及接口

`shared/communication.js` 定义合法阶段、目标形状、固定无线电、文字格式、转盘方向与回放时间窗。

请求举例：

```js
{ t: 'g.ping', phase: 'PREP', round: 1,
  target: { kind: 'tile', playerId: 'p_0', row: 9, col: 2, intent: 'danger' } }
{ t: 'g.radio', phase: 'PREP', round: 1, id: 0 }
```

目标为 `strategy`、`life`、`bond`、`tile`、`piece`、`level`、`shop`、`funds`、`enemy`。只提交身份及目标标识，不提交自由文字、费用、生命值、装备名称。精确形状校验拒绝额外字段。

`server/match/communications.js` 校验当前回合、阶段、参战资格、正在查看的战场、目标存在性及权限，从真实 Match/PlayerState 生成 `m.communication`：事件 ID、服务器时间、回合、阶段、发送者、目标、展示数据及可选地图坐标。客户端按事件 ID 去重。商店和资金仅限本人；战斗中不允许标记已部署单位和敌人。Windows 标点与无线电独立限流：标点最短 125ms、滚动十秒 40 次；无线电最短一秒、十秒五次，仅成功发送计数。无效目标不替换、断线不排队补发。

HUD 使用 `data-comm` 元数据；地图命中调用 `pickCommunication(clientX, clientY)`，标识投影调用 `fieldTileScreen(row, col)`。渲染引擎及 DOM 降级均实现这两个只读接口。服务器使用实际 `deployFieldOf` 和 `fieldTile` 映射最终攻势左右半场及联防偏移；回合变化使旧地图标识不可见。

昵称文字不显示代码，身份比较仍使用 `playerId`。装备零、一、两件采用不同文字；干员、补位、自选及召唤物名称读取真实展示记录。盟约人数、阈值、层数和禁用状态复用现有计算。

## 快捷键升级

旧配置缺少标点／无线电动作时，先保留 Z／X 给新动作，其余不冲突的自定义键继续使用；冲突旧动作依序分配空闲 C、V、B、N、M、Delete（全部占用时继续寻找其他空闲可绑定键）。迁移结果自动保存在设备设置，并在设置列表显示具体动作的前后按键。账号配音及干员配置不受影响。

## 回放与容量

`MatchRecorder` 单独保存 `communications`，不混入用于状态恢复的 `events`，不保存额外玩家状态或战斗快照。结算摘要不传输通讯轨道，回放过期后清除通讯轨道。旧回放缺少该轨道时视为空。

回放使用播放时间恢复最近 8 秒消息和最近 4 秒地图标识。暂停冻结寿命；跳转、倒退、玩家切换重新计算。显式跳转带修订号，短距离向前跳转也不播放无线电音效；连续向前播放才播放，音效间隔按真实时间至少一秒。

保留现有 gzip 存档和 100 MB 单份上限。容量测试构造四人、14 个五分钟回合、每人每两秒一条通讯的 8400 条事件，验证通讯轨道压缩后低于 2 MB；这只衡量新增通讯开销，完整回放仍受现有存档上限约束。

## 验证命令与结果

使用项目 `.runtime/node-v24.19.0-darwin-arm64/bin` 中的 Node.js 24；常规命令：

```sh
npm test
npm run lint
npm run typecheck
npm run check:imports
node tools/i18n.mjs check en --strict
SP_COMM_E2E=1 node --test test/ui/communications.e2e.test.js
SP_E2E=1 node --test test/ui/hotkeys.e2e.test.js
SP_SOCIAL_E2E=1 node --test test/ui/social.e2e.test.js
```

浏览器测试使用临时本地服务器、独立 Chrome 环境及临时账号目录，结束时关闭服务器。测试截图在 `test/e2e/out/communications/`。专用 Chrome 联机验收已通过，覆盖独立窗口同步、真实引擎地块拾取、购买拦截、无线电、观战发送拒绝、不同战场仅文字、转盘取消、4 秒标识过期、DOM 降级投影、844×390 触屏按钮与真实触屏长按／拖动／松开、真实存档读取、回放暂停／跳转／倒退与禁止发送、断线清理，以及 `/healthz`。

导入检查沿用上游默认命令，保留 `server/sim/nodeData.js` 的三条 Node 内置导入记录（该文件为既有 Node 专用加载器，不被浏览器加载）；本功能无新增边界记录。
