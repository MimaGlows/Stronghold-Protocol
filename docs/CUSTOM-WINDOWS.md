# Windows 定制合并：v0.2.2

2026-10-09，以官方 v0.2.2（62eb113419123d9a3a63606107bbf85230c5dd2f）合并 Mac 定制分支 023f291a67129beb0ed62ef03c49a3167966d7ed。完整保留虚拟账号、头像、服务器历史结算、匿名回放分享、接管确认、账号配置同步及中日配音。战斗规则、确定性引擎与 golden 场景采用本次官方更新。

## 集成约定

- `voiceLanguage` / `voiceOverrides` 为现有账号配置字段；兼容读取官方 `voiceLang`，默认仍为日文。素材解析兼容官方 `audio.voice` / `audio.voiceJp` 与定制 `audio.voices`，保留按干员覆盖和逐条中文回退。
- 新增潜能、练度的 `ops` 与技能／模组一起经 `room.loadout` 持久化到账号配置。恢复、离线重试及账号切换均包含 `ops`，避免只有当前浏览器保留设置。
- 官方统计四页与定制历史已统一为服务器虚拟账号数据，不再使用本机统计。官方 `ResultView` 同时用于实时结算、统计详情及定制历史；回放／分享动作仅出现在可归档的结算中。
- `public/hosting/` 独立注入两行署名，只出现在首页和模拟选择页；保留首页版权与官方统计入口；首页和选择页的独立历史入口已移除，大厅及对局／回放无署名。
- 保留 80 KiB HTTP 请求头、64 KiB WebSocket 入站限制、本人头像权限以及大头像协议验证。
- 不回退到首页旧头像入口或 Cookie-only 头像保存；不引入账号密码体系。
- 非中文界面新增定制条目沿用已有英文翻译作为回退；官方翻译完整保留。

## 数据与部署

正式切换携带当时 Windows 实例完整的 `logs/`，不以最初 Mac 快照覆盖新产生的数据。验收账号、房间、回放全部使用独立 `qa-data/`。官方规则变化会改变回放内容指纹；旧版回放可能显示版本不匹配，保留原历史结算及归档文件，不改写旧帧。

正式包使用官方生产依赖和现有 Windows Node.js 24.19.0。开发依赖仅在隔离源码目录。双击入口仍绑定 `127.0.0.1:3000`、`SP_COMBAT=client`、`SP_VERIFY=off`，保留现有 SakuraFRP 隧道，不增加自启或防火墙规则。

## 升级维护

后续升级需重新合并上述账号、头像、历史、回放、配音、接管与署名定制，尤其检查新增账号配置字段的持久化和跨浏览器恢复。不能直接以官方完整包覆盖定制代码。源码 bundle、相对 v0.2.2 的补丁、校验清单和本机检查记录在实例旁的升级归档中。
