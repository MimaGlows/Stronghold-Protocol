# 自订模拟实验交付记录

本轮仅修改 `Stronghold-Protocol-Matchmaking`。规则与公式见 [实验规则](CUSTOM-SIMULATION.md)。

## 本轮修订

- “悬赏狂欢”按实际悬赏选择事件切池，不固定在某个回合。第一轮使用第一轮精英；第二轮选择完成后使用第二轮精英，并一直保留该池。每回合按去重后的种类确定性随机抽取一种，再应用敌人数量倍率。
- 必选盟约在开局重抽后仍受保护；金币和盟约层数的余数跨回合保留。
- 原版普通 Golden 不更新；自定样本使用独立 `test/golden/custom-v1.json`。

## 界面与动效

沿用原版黑灰、薄荷绿、斜纹与切角。保留三模式并排、左侧真实配置摘要、右侧竖排玩家及独立观察者。自订模式选中时降低匹配按钮亮度，让创建自定房间成为主动作。移除底栏重复时限文案，改为准备人数。

房间进入240毫秒、换位200毫秒、设置弹窗220毫秒；完整动画和减少动画沿用现有选项。浏览器记录实际变换与时间进度，而不只检查最终样式。

两轮独立静态视觉评审：初评7/10，修正主动作层级、手机控件尺寸、协议摘要和选择控件后复核8/10。剩余提升为数字单位排版与滚动边界。评审者能打开HTTP录屏，但工具未连续呈现关键动画，故没有宣称连续观看下的动效手感通过。

证据位于 `test/e2e/out/custom-v1/`：`00-three-modes.png`、`01-six-seats.png`、`02-contracts.png`、`03-mobile.png`、`04-mobile-settings.png`、`05-time-limit.png`、`06-custom-motion.webm`、`motion-progress.json`。
