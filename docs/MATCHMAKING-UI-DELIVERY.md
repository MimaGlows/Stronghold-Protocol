## 方向与改动

开始匹配旁只保留黑名单管理。点击开始或组排准备，进入图标选择弹窗；每次明确选择一个盟约或不限后才能确认。选择失败保留输入；个人偏好仍按账号保存。新队员和队长初始未准备，全部确认后自动搜索。任意成员取消准备均中止整队搜索并重置准备，保留好友队伍。
