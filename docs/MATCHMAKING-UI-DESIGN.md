# 匹配界面设计说明（2026-10-13）

北极星：选择盟约像确认作战声明，队伍搜索像争锋频道的状态终端。

这是合作游戏的任务界面。玩家要快速确认偏好、看清准备状态、随时退出搜索。使用现有薄荷绿与石墨灰、中文粗标题和Bender编号、切角按钮、原始盟约图标；用户已明确选定品牌与参考，不另做风格候选。普通房间保持原有逻辑，仅保留补位开关。

## 状态与操作

- 开始匹配旁的盾牌图标只管理黑名单。
- 单人点击开始匹配、组排成员点击“选择同盟并完成准备”。弹窗展示八个核心盟约及不限，必须点击一个选项才能确认。非法盟约明确禁用，焦点与选择状态分开。
- 确认请求原子保存偏好和准备；失败保留弹窗及选择。重复、过期版本和过期尝试不重复开局。
- 新成员未准备，队长也须选择；最后一位确认自动搜索。任意成员取消准备会退出搜索、清空全员准备，好友队伍保留。
- 未准备为黑底宽松布局，显示博士代号、盟约名、准备状态。开始搜索才收紧四头像，隐藏姓名与盟约名并改用右下角盟约图标；取消后反向恢复。搜索中操作区只有取消准备。
- 超时淡红提示保留；普通补位房间不显示盟约选择。

## 动效与设备

按下100毫秒反馈、选中底线150毫秒展开；弹窗220毫秒进入和160毫秒退出。首次队伍280毫秒由底部进入，首次单排360毫秒从屏幕底部进入；已有队伍原位320毫秒展开和FLIP收紧，黑底与荧光薄荷绿（#59f4ca）双向320毫秒过渡。搜索图标420毫秒从左侧突入，结束后9秒一周慢转；取消时320毫秒收回。成员出现／移位180毫秒、离开和准备标记160毫秒、超时提示180毫秒。业务请求与开局不等待动画。

使用原生Web Animations API按服务端尝试ID及状态驱动，一秒计时刷新不重启循环；取消和新尝试会清理旧动画，尺寸变化清理旧布局测量。头像先在中间完成320毫秒收紧，再用180毫秒整体向右平移，最终与取消按钮保持间距；取消从当前位置反向恢复。弹窗为动画区块的兄弟节点，避免祖先transform影响固定定位；关闭动画期间释放焦点约束并禁止交互。

匹配动画设置默认full、另一选项reduced，保存至实验版settings偏好，旧记录自动补full。完整模式在本机系统关闭动画时仍播放，仅作用于匹配组件；减少模式取消动画并直接呈现最终状态。未更改系统动画设置或其他页面策略。

手机保持横屏，图标与操作文字设可读下限。弹窗正文可滚动，确认按钮保留在弹窗底部。键盘可Tab、回车选择，Esc关闭；处理中防止重复确认。

2026-10-13 按用户后续要求，准备和搜索区块均固定覆盖窗口底部、横向铺满，不为底部两行署名文案避让。大厅正文增加滚动范围，以便将核心操作滚动至区块上方；不按区块高度压缩正文。黑名单按钮保持独立并与开始匹配留出至少12px间距，最小宽度不再越过网格边界。盟约窗口取消和确认采用同一大号按钮规格，文字与按钮中心对齐。头像限制与敏感代号改用明确弹窗；邀请系统通知包含博士、难度和目标类型。见[本轮交付](MATCHMAKING-FEEDBACK.md)。

后续动效及音效：沿用薄荷绿战术终端方向，以匹配成功的确认扫光为主角。成功条1100毫秒展示，扫光640毫秒，确认徽记260毫秒，头像220毫秒依次显现；覆盖新页面但不捕获输入、不延迟路由或开局。离开队伍及取消搜索时，原区块从当前位置向窗口下方240毫秒移出；取消准备同时恢复保留的黑底好友队伍。好友列表及边缘把手280毫秒展开、180毫秒收回，列表行保留至收回完成，过程中可反向。匹配动画的完整／减少设置同时控制这些组件，减少模式直接到位，成功信息静态保留一秒。开始、取消／离队、成功分别复用现有start、matchCancel、matchSucceed内置音效，沿用音效音量和静音。详见[本轮动效交付](MATCHMAKING-CUES.md)。

## 减法、素材与证据

删除偏好下拉、搜索区的可见姓名及盟约名称、重复设置入口和说明卡。序号帮助确认席位，选中通过勾号及底线共同表达。复用现有游戏资产和图标，不生成游戏素材或增加动画依赖。

上版基线在test/e2e/out/matchmaking-v3/，完整动效证据在test/e2e/out/matchmaking-v4/。功能及手机横屏用四个隔离Chrome账号验证，完整动效交付见[MATCHMAKING-MOTION.md](MATCHMAKING-MOTION.md)。
