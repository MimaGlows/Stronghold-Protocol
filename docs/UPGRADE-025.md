# MimaGlows 定制版 v0.2.5 升级

以官方 v0.2.5 标签 cf7a9400270d5aa79b2e601e405dab782e25f120 为上游基线，保留 Windows 虚拟账号、头像配置、服务器统计、最近30条回放、通讯、配音与自制继续对局；合入已验证的回放扫描 Worker 和3002最新匹配队列、准备选择与动效。

原普通对局采用0.2.5 Golden。上游六组Golden文件按0.2.5原样接收；本版匹配规则使用专项测试，不改普通对局结果。生成数据从上游构建工具与官方标签取得，不手工修改生成数据。官方场景资源来自已验证SHA-256的0.2.5更新包。旧完整回放继续按结构兼容播放；未完成的模拟轨道仍须匹配引擎版本，已失效轨道不恢复。

3000先切换至独立新版目录，3001保留原代码与原数据。验证完成后关闭3002，保存实验目录。用户确认3000后，才部署3001、上传master并发布v0.2.5-mimaglows.1。发布包与Git提交均不得包含玩家资料、环境配置或控制凭证。

匹配规则及接口见[MATCHMAKING.md](MATCHMAKING.md)。验证结果、构建号与本机回滚入口在交付报告中记录。

0.2.5的重建战斗可能早于客户端记录的结束时间完成。回放生成器在记录的结束时刻补一帧最终静止状态，不添加战斗事件，保证时间轴完整。专项14回合四人回放测试通过。Windows场景资源测试使用fileURLToPath解析文件URL。
