# 0.2.6 统一构建与修复交付

日期：2026-10-15。3000、3001、3002采用同一功能、匹配规则及构建，保留各自账号、统计、回放与运行目录。3002保留实验界面标记。上游为 sganggs/Stronghold-Protocol 的 v0.2.6（488db49f11daf862b67ce26fa4cf89aa6cba2466）。

## 应用名称与隔离

Android/桌面安装清单的 name、short_name，iOS 主屏幕名称，以及网页标题统一为“优化版卫戍”。已经安装的旧快捷方式可能仍保留旧名称，可移除后重新添加。游戏内实验标记不作为安装名称。

浏览器命名空间分别为 sp、sp.3001、sp.matchmaking；3001仅迁移其自身来源的旧浏览器记录，迁移一次后不恢复已退出的登录状态。头像Cookie独立。三个实例的共同构建依据文件内容计算，与复制后的修改时间无关。

## 游戏修复

- 额外普通回合采用原版第13回合模板及基础数值，单人采用最后一个原版普通回合；保留原强化序列和自定倍率，避免第16回合起回退至1倍。
- 隐藏核心仅能在原主BOSS之后触发一次，第19回合成功或失败直接结算；重复、延迟回调不能回退回合。自定隐藏核心失败不再按胜利推进，普通模式保留原结算逻辑。
- 自定及适用匹配规则的对局禁止整局重刷，服务端同时校验；商店刷新不变。
- 隐秘战争继续隐藏战前情报及盟约选择，允许原版观战。单击头像打开面板，点击“前往查看”切换，双击快捷操作保留。服务器战斗支持联防左右与全景视角、返回及重连。
- 权威漏怪变化触发合并公共更新，不提高战斗快照频率。生命红底显示待结算损失，遵循落网之鱼、白鸟河滩及游客规则，不提前扣正式生命。

## 验证与实测边界

完整测试6688项：6645通过、43按环境跳过、0失败。随后新增隔离迁移/停服测试4项通过；最新客户端/服务器相关回归411项通过。lint、类型、导入检查通过。原版287个Golden保持一致，未改普通夹具。两至四人终极、中性自定R1–14的实际生成敌人数值与普通同盟一致，未额外提高原版倍率。

七个独立浏览器上下文验收六人及观察者，覆盖两步观战、隐秘战争、连续漏怪、联防视角、重连、1440×900和844×390。最新独立运行0页面错误，稳定阶段生命红底更新P95为116.92毫秒。初次渲染/加载样本单独记录，最高3.89秒；与CPU密集检查并行时曾有867.65毫秒P95，不能将隔离结果解释为高负载下的保证。

压测仅使用本机代理，不修改真实隧道。两间极端六人自定房间120秒：平均发送1.176Mbps，事件循环P95 32.72毫秒，单核CPU占用P95 40.95%，代理队列无积压。合法六人联防60秒：0.362Mbps、事件循环P95 18.01毫秒、操作P95 16.36毫秒，无错误。当前版为短时复测，不宣称完成新的30分钟耐久；其他实例和真实隧道流量未知。按共享24Mbps预留25%余量，条件为所有流量之和≤18Mbps，不能据上述单项平均值直接推断并发上限。

证据：test/e2e/out/custom-gameplay-fix/ 下的PNG、03-unite-camera.webm及latency.json；维护工作目录包含完整测试日志、load/stages.jsonl、load-unite/stages.jsonl、部署清单与备份。
