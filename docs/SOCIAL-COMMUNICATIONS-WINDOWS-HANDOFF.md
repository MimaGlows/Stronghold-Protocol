# Windows 0.2.2：好友、标点和无线电

实施日期：2026-10-09。依据 `WINDOWS-SOCIAL-COMMUNICATIONS-PROMPT.md` 在 Windows 定制 0.2.2 上实现；用户确认没有 Mac 源码，因此没有直接套用 0.2.1 补丁。原基线 bdb12a60ab78921c55c206c3cead41087c532913，生产构建 dec49f524cef，原回放内容指纹 87791433132c6348b4b0。部署状态和最终实际检查数量见实例旁验收报告；本文件本身不表示已上线。

## 使用与权限

模拟选择页和同盟大厅右侧提供默认收起的好友抽屉，含好友、最近玩家和代号／四位编号搜索。搜索不会创建账号，模糊搜索最多返回 20 个现有账号。好友单向添加，上限 200 人；完整 `博士代号#四位编号` 区分同名玩家。好友和隐私归属服务器档案，账号切换清空本地缓存。

最近玩家来自最近五场正常结算，独立模拟也占一场；保留曾退出的真人队友，排除本人、AI、观战者和重复身份。旧账号首次加载从现有服务器统计与归属明确的归档补齐一次，回放过期不删除近期参与者索引。

头像和代号打开官方“统计 → 对局记录”，可继续进入既有结算详情和回放。查看权限由被查看账号的单向名单决定：本人始终可看；其他人按 `none`、`friends`、`friends_recent` 判断。每次 HTTP 读取都重新检查当前在线会话和权限，不公开能力密钥或分享码。默认允许好友加入／观战，资料默认好友及近期队友可见。关闭入口只约束好友路径，房间代码和直接邀请沿用原机制。

邀请仅来自等待中的同盟房间，120 秒有效，同一邀请方向 30 秒冷却；重启失效，不预留位置。接受前重新检查资格、房间、阶段和容量，失败保留原等待房间；不自动挤掉 AI。当前账号在任何窗口仍参战时，必须走原接管批准流程。独立与同盟均有最多两个观战席位，观战者只能接收通讯。

系统通知仅在用户主动点击授权、浏览器支持且安全上下文时启用；点击通知聚焦并展示邀请，不自动接受。普通 HTTP 或不支持通知时使用页面内邀请。

## 通讯和快捷键

按住标点键（默认 Z）点击 HUD 或地图；触摸入口提供切换模式。地图短按发位置，300ms 长按转盘：上危险、右敌方消失、左干得漂亮、下或中心取消。释放按键、Escape、真正的窗口失焦、pointercancel、断线、离局、账号切换取消未发送操作；断线不排队重发。

无线电默认 X，五项固定消息，不允许自由文本。与交流菜单互斥。出售默认由 Z 改为 C。旧设备快捷键迁移先预留 Z/X，保留不冲突自定义键；冲突动作分配空闲 C/V/B/N/M/Delete，候选用尽再找合法空键，明确显示原键到新键。改键仍使用原交换机制，快捷键仍按设备保存。

标点支持策略、真实生命、等级、资金、盟约、地图、棋子／装备、商店及敌方预览。服务端根据当前状态生成名称、费用、装备和位置；客户端不能提交权威展示文本。战斗阶段不能标单位／敌人，可以标合法空部署地块。标点与无线电共用每秒一次、滚动十秒五次的服务端限流。消息最多显示五条、寿命八秒，地图标识四秒且限当前回合／战场，不自动切镜头。

提示音复用 yourTurn，服从音效音量和静音，至少间隔一秒，不占干员人声通道。暂停回放冻结寿命，跳转／倒退／切玩家重算窗口；任何显式跳转均静音，仅正常向前播放跨过无线电事件时提示。

## 协议、数据与兼容

新增 C2S：`social.sync/search/add/remove/avatar/join/spectate/invite/inviteRespond`、`profile.privacy`、`g.ping`、`g.radio`。社交响应含完整 `profileKey`，搜索含请求号；头像按身份及修订号缓存并按需获取。S2C 为 `social.state/presence/search/avatar/invite/inviteEnded`、`m.communication`。错误保留原 code，新增可翻译 userMessage；不扩大自由广播权限。WebSocket 入站继续 64 KiB。

`g.ping` 包含 round、phase 和严格目标结构；`g.radio` 包含 round、phase 和整数 id 0–4。拒绝多余字段、原型对象、伪造权威数据、过期回合／阶段／商店／单位、越权和不合法部署地块。地图位置保留原棋盘与映射坐标，沿用真实战场部署转换、联防偏移及最终攻势镜像。

`/api/social-history` 使用当前会话 Bearer token，仅查询已授权目标的正常结算；每页最多 50 条且紧凑行约 40 KiB，含 revision/offset/next。详情和回放保持现有播放器，不再建立独立记录列表。401/403/404 分别处理，撤销权限清空已加载资料，账号切换忽略旧响应。HTTP 头继续 80 KiB。

档案新字段：friends、socialRecentMatches、socialVersion，以及 preferences.socialPrivacy；沿用原子保存。邀请、在线状态和订阅只在进程内。正式数据在 `logs/replays/profiles` 与 `logs/replays`；验证数据仅位于隔离目录 qa-data，不进入正式实例。伪账号没有新增密码体系。

回放新增独立 communications 轨道，仅保存服务端接受的展示事件与对局时钟，不混入恢复操作或复制战斗快照。gzip 存储、默认完整存档 100 MB 上限保留；旧回放缺轨道按空列表处理，摘要省略、过期清空。8400 条通讯轨道压缩小于 2 MB 的测试仅验证轨道容量，并不承诺完整对局必然小于 100 MB。

沿用 Windows 现有最近 30 条对局记录回放保留规则，退出记录占名额但不生成回放；不会重新引入 Mac 文档的 72 小时期限。旧显式 TTL 存档和版本不兼容原因仍兼容，不恢复失效帧。源码变化会改变指纹，新旧实际失效数量必须记录在切换报告中。
